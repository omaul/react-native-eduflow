# Гайд по иконкам

## Философия: иконка рассказывает историю

Каждая иконка — это не просто пиктограмма, а маленькая сцена. У неё есть:

1. **Основная форма** — чистый, узнаваемый силуэт (папка, список, солнце, луна)
2. **Деталь-история** — один маленький элемент, который добавляет контекст и оживляет сцену

Деталь должна быть **смысловой**, а не декоративной:
- Луна + крестик-звезда + точка-звезда = ночное небо
- Солнце + полупрозрачный ореол = тёплое свечение
- Папка + уголок страницы + точка = внутри есть документ
- Список + галочка = задачи, прогресс

**Плохо:** случайные точки "для красоты", элементы без связи с иконкой.
**Хорошо:** каждый элемент можно объяснить одной фразой.

## Технические правила

### Общие параметры (iconDefaults)
- `viewBox="0 0 24 24"`, размер по умолчанию `width="20" height="20"`
- `fill="none"`, `stroke="currentColor"`
- `strokeWidth="1.5"` — единая толщина для всех элементов
- `strokeLinecap="round"`, `strokeLinejoin="round"` — мягкие углы и концы
- `aria-hidden="true"`

### Цвет
- Только `currentColor`. Никаких хардкод-цветов.
- Иконка наследует цвет от контекста.

### Заливка
- Допустима для маленьких акцентов (`fill="currentColor"`, `stroke="none"`).
- Используй для точек-частиц, буллетов, мелких форм.
- Основные формы — только обводка.

### Прозрачность
- `opacity` допустим для создания глубины (0.2–0.4).
- Максимум один полупрозрачный элемент на иконку.

### Сложность
- Максимум 4–6 SVG-элементов на иконку.
- Если можно убрать элемент без потери смысла или истории — убирай.
- Деталь-история не должна налезать на основную форму или создавать "кашу".

### Генеративный характер
Связь с p5.js фонами достигается не через копирование частиц, а через:
- **Мягкость** — round caps/joins, плавные формы
- **Лёгкую асимметрию** — буллеты чуть разного размера, лучи чуть разной длины
- **Ощущение пространства** — ореолы, глубина через opacity, "далёкие" объекты

## Чеклист при создании новой иконки

1. Какая основная форма? (должна читаться мгновенно)
2. Какую историю она рассказывает? (одно предложение)
3. Какая деталь оживляет сцену? (один маленький символ или приём)
4. Можно ли объяснить каждый элемент? (если нет — убери)
5. Не налезают ли элементы друг на друга при размере 20x20?
